Paperbranch uses local Markdown. Approved specifications live in `docs/specs/`. Implementation tickets live in `.scratch/<feature-slug>/issues/`. See `docs/agents/issue-tracker.md`.

Paperbranch is a single-context repository. Read `CONTEXT.md` and the relevant ADRs in `docs/adr/` before planning or implementation. See `docs/agents/domain.md`.
